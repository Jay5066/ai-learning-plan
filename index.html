A level counts as reached when every item in that month and all earlier months is checked.

  • 0Level 0: No regular AI use.
  • 1Level 1: Uses chat LLMs well and understands tokens, context and hallucinations.
  • 2Level 2: Uses Copilot in VS Code daily (chat, inline, agent) and reviews diffs critically.
  • 3Level 3: Configures AI tooling (instructions, custom agents, skills).
  • 4Level 4: Drives agentic coding with Claude Code on real projects.
  • 5Level 5: Calls LLM APIs with structured output and tool calling.
  • 6Level 6: Builds RAG with embeddings and a vector database.
  • 7Level 7: Builds agents (LangChain/LangGraph) and MCP servers.
  • 8Level 8: Runs open and local models (Hugging Face) and always-on agents (OpenClaw).
  • 9Level 9: Tests, evaluates and secures AI features; uses spec-driven development.
  • 10Level 10: Ships and operates an AI feature in production and can teach others.
